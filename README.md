# MedLens — AI-Powered Clinical Information Intelligence

MedLens transforms fragmented clinical information, lab reports, and intake notes into an organized, traceable, and reviewable patient record.

## Core Capabilities
- Patient Information Intake with User Provenance
- Reference-Range Aware Lab Extraction (Normal, High, Low)
- Inconsistency and Conflict Detection
- Patient-Friendly Clinical Summaries
- Human-in-the-Loop Data Verification & Editing
- Export to Standardized Medical Record PDF
